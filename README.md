## ToDoList-.NET-MVC
A .NET MVC web application, made by Daniel Tenev in 2024.

A simple task management web app for creating, filtering, and completing to-do items organised by category and due date. This project was built as a personal one while learning ASP.NET Core MVC and Entity Framework and doesn't act as a production system.

## Built with:
— C# / .NET 8, ASP.NET Core MVC  
— Entity Framework Core  
— SQL Server LocalDB  
— Bootstrap 5 for styling
